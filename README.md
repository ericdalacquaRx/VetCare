## Objetivo do software
O VetCare é um sistema desktop desenvolvido para auxiliar a gestão de uma clínica veterinária, permitindo o controle organizado de tutores (donos dos animais), dos pets atendidos e do histórico de consultas realizadas.

## Funcionalidades do sistema (requisitos)
- RF01: Cadastrar tutores (nome, telefone, e-mail e endereço)
- RF02: Cadastrar pets vinculados a um tutor (nome, espécie, raça e data de nascimento)
- RF03: Registrar consultas vinculadas a um pet (data, motivo, diagnóstico, veterinário responsável e valor)
- RF04: Listar o histórico de consultas de um pet
- RF05: Listar os pets de um tutor
